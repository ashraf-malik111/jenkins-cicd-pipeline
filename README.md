# Jenkins CI/CD Pipeline

This project demonstrates a CI/CD pipeline implementation using Jenkins, GitHub, Maven, Docker, and Kubernetes.

## Technologies Used

* Jenkins
* GitHub
* Maven
* Docker
* Kubernetes

## Pipeline Stages

1. Source Code Checkout
2. Build Application
3. Unit Testing
4. Code Quality Analysis
5. Docker Image Build
6. Docker Image Push
7. Kubernetes Deployment

## Benefits

* Automated Build Process
* Faster Application Delivery
* Reduced Manual Effort
* Consistent Deployments
